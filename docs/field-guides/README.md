# Condition Monitoring — Field Guides

Practical guides for technicians taking readings on the Mechbase marine demo routes.

| Guide | Sensor / Instrument | Measurement |
|---|---|---|
| [Vibration](vibration.md) | TE Connectivity WVS wireless tri-axial accelerometer | Velocity (mm/s RMS) |
| [Thermography](thermography.md) | FLIR Edge series handheld thermal camera | Surface temperature (°C) |
| [Ultrasound](ultrasound.md) | Handheld ultrasonic detector | Signal level (dB) |

Each guide covers the instrument, how to set it up and take a reading correctly, and how to enter the result in Mechbase.
